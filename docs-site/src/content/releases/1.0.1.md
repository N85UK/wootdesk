highlights:
  - "Unsent drafts survive the app being closed, filed under the server profile they were written in."
  - "Previously loaded messages stay readable when a refresh fails, labelled as a saved copy with the time it was captured."
  - "A send whose result cannot be confirmed is represented as uncertain rather than as sent or failed, and a retry asks for confirmation first."
  - "Executable and script attachment types are refused before the file is read."
  - "Removing a server profile deletes its drafts, cached messages and unconfirmed-send records."
  - "Offline storage can be switched off, which also deletes anything already stored."
security:
  - "Offline records are protected at rest, filed per server profile, and excluded from device backups."
  - "Attachment addresses are re-validated when a saved copy is read back, so an edited cache file cannot widen what the app will open."
compatibility:
  - "No change to the supported Apple or Chatwoot versions."
knownIssues:
  - "There is still no automatic retry of an unconfirmed send. This is deliberate, because Chatwoot's message API has no idempotency key."
upgradeAction: No action is required. Offline storage is on by default and can be switched off in Settings.
