This build is the first to carry the complete conversation workflow rather than
a vertical slice. It is a **TestFlight** build for a closed internal group, and
it is not a public release. Nothing here should be read as an announcement of
App Store availability.

## What was verified

The source passes the full local continuous integration path: macOS and iOS
Simulator builds, the Swift test suite, the push gateway test suite, and the
performance regression checks. The user-interface journeys were re-run on
iPhone 17 Pro and iPad Pro 13-inch simulators, and on an iPhone 17 Pro Max
running iOS 27.0.

The conversation workflow was verified against a live Chatwoot v4.9.0 server
holding invented records, including the mutating triage operations.

## What was not verified

Physical iPad and Mac acceptance is not recorded. Remote notification delivery
has not been exercised end to end. Neither is claimed as working.
