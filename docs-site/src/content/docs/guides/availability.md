---
title: Availability
description: Setting your agent availability for the connected Chatwoot account.
sidebar:
  order: 5
---

Set your availability from Settings. The three states are Chatwoot's own:

| State | Meaning in Chatwoot |
| --- | --- |
| Online | Available for assignment |
| Busy | Working, but not taking new assignment |
| Offline | Not available |

Availability is **per account**. If you have several server profiles, each one
carries its own availability, because each is a different agent identity on a
different Chatwoot account.

The change is confirmed by the server before WootDesk shows it. If the update
fails, the previously confirmed state stays on screen rather than the app
showing a state Chatwoot does not have.
