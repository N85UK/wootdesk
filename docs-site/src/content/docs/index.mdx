## What it is

WootDesk is a native SwiftUI application that connects to a Chatwoot server you
already have. It uses the Chatwoot Application API with a personal access
token, which stays in the Apple Keychain on your device. WootDesk does not host
a Chatwoot service, and it does not proxy your conversations through anyone
else's server: the app talks to your server directly.

It is built for support agents who want their queue on Apple hardware without a
browser tab, and for teams self-hosting Chatwoot who want a client they can
read the source of.

## Relationship to Chatwoot

WootDesk is an independent project by N85. It is **not** affiliated with,
endorsed by, or sponsored by Chatwoot, and it is not an official Chatwoot
product. It talks to Chatwoot's documented Application API in the same way any
third-party client would. Compatibility is verified against the versions listed
in [Requirements](/start/requirements), and a Chatwoot upgrade can change
behaviour without notice from us.

## What works today

| Area | State |
| --- | --- |
| Connect to a server and pick an account | Available |
| Browse, filter, page and search conversations | Available |
| Read message history, including older pages | Available |
| Send replies and private notes | Available |
| Send and receive attachments | Available |
| Triage: status, snooze, priority, assignment, labels | Available |
| Set your availability | Available |
| Drafts and recent messages kept through a lost connection | Available |
| Push notifications that open the right conversation | App side complete, delivery not yet switched on |
| Live updates without refreshing | Planned, not built |
| AI summaries and drafting | Planned, not built |

See [What's new](/releases) for what each build actually contained.
